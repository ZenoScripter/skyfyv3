# SKYFY rebrand and UI rebuild

- Android application ID: `com.wildan.skyfy`.
- Android launcher label: `SKYFY`.
- Dart package name intentionally remains `musify` to preserve upstream imports and plugin compatibility.
- The app's playback, search, download, playlist, library, lyrics, equalizer, storage and routing services are retained from the supplied Musify source tree.
- The Home screen and Profile hub have been rebuilt in the SKYFY dark-violet visual language.
- Search, Library, Now Playing, Settings and About remain connected to the retained application services/routes.
- Upstream copyright notices and GPL-3.0 license are retained. This is an independent modification, not an official upstream product.
- The Flutter SDK and Android build toolchain were not available in this environment; APK compilation and runtime testing have not been performed.
